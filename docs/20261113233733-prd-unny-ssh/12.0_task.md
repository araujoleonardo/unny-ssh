- Projetos registrados reaparecem após desbloqueio e executam no diretório e servidor indicados.
- Down padrão preserva volumes; opção destrutiva exige confirmação adicional.
- Cancelamento informa que efeitos já executados podem permanecer; comandos não são repetidos automaticamente.
