## Success Criteria

- Após bloqueio completo não há sessão ativa nem conteúdo remoto exibido; eventos tardios são ignorados.
- Rascunhos retornam após desbloqueio sem publicação automática no servidor.
- Falha de disco não descarta buffers nem declara bloqueio completo falsamente.
