## Success Criteria

- Reabrir o aplicativo exige senha; copiar o cofre não revela perfis ou segredos.
- Senha incorreta, adulteração e escrita interrompida preservam a última geração válida.
- Troca de senha concluída invalida a senha anterior e mantém todo o payload legível com a nova.
