## Overview

Conectar perfis por SSH e gerenciar sessões independentes com validação prévia da identidade do servidor.

- Seguir AGENTS.md: npm, contratos consistentes, validação pertinente e proteção de segredos.

## Requirements

- Suportar senha, chaves OpenSSH Ed25519/RSA SHA-2 e SSH Agent nativo, inclusive via VPN externa.
- Validar host antes de autenticar, bloquear chave alterada e usar desafio de confirmação com expiração.
- Editar perfil não altera sessão ativa; reconectar não repete operações mutáveis.

## Success Criteria

- Cada autenticação conecta aos servidores de teste nos três sistemas; Agent ausente gera erro recuperável.
- Servidor desconhecido exige confirmação; chave alterada impede autenticação até revisão explícita.
- Duas sessões coexistem sem misturar eventos e perfil alterado só afeta novas conexões.
