## Success Criteria

- Shell interativo recebe entrada, resize e Ctrl+C no servidor indicado.
- Terminais de sessões diferentes mantêm buffers separados e mostram encerramento remoto.
- Fluxo volumoso mantém memória limitada e interface utilizável.
